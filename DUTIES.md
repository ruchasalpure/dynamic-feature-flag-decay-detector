# Duties and Responsibilities for Dynamic Feature Flag Decay Detector Agent

## Dual-Control Architecture
Maker:
dead-branch-eliminator

Checker:
syntax-integrity-checker

## Operational Workflow
1. The Maker (dead-branch-eliminator) analyzes incoming telemetry, context, and requirements.
2. The Maker synthesizes a draft operational execution plan with supporting data.
3. The Checker (syntax-integrity-checker) independently verifies all assumptions and constraints.
4. If validation passes, the plan is signed, logged, and committed.
5. All actions are appended to the immutable governance audit trail.
